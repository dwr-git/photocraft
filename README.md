# AI-Photoshop

Фоторедактор уровня Photoshop прямо в браузере — со встроенным помощником на вашей
собственной локальной модели. Помощник подсказывает, где что находится, и умеет сам
выполнять действия в редакторе: открывать команды, настраивать диалоги, нажимать OK.

**Установить на сервер:** [studio/README.ru.md](studio/README.ru.md) — скачать zip из
Releases, распаковать, положить папку. Ничего компилировать не нужно.

## Что здесь добавлено к исходному редактору

- **Помощник** (`studio/`): панель справа от редактора, режимы «Совет» и «Сделай»,
  видит экран (мультимодальная модель), каждое действие можно отменить.
  Сервер помощника — один PHP-файл, работает через `auth.php`, `config.php` и Ollama вашей системы.
- **Мост JavaScript → редактор** (`apps/photocraft-web/src/control_bridge.rs`): страница может
  вызывать любые из 500+ команд редактора и читать его состояние.
- **Две неоморфные темы** — светлая (мягкая холодная голубая) и тёмная: панели и кнопки
  «выдавлены» из поверхности мягкими тенями, выбранные инструменты «вдавлены».
- Интерфейс по умолчанию на русском; полностью автономная работа — всё грузится из своей папки.

## Сборка

GitHub Actions собирает готовую папку на каждое изменение ветки `main`
([.github/workflows/studio.yml](.github/workflows/studio.yml)) и выкладывает zip в Releases →
«Последняя сборка». Локально (нужны Rust, trunk и цель wasm32): `studio/build/package.sh`.
