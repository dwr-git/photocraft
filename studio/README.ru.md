# PhotoCraft Studio — установка на сервер

Фоторедактор в браузере (PhotoCraft) с встроенным помощником на вашей локальной модели.
На сервере нужны только **nginx + PHP + Ollama** — то, что у вас уже есть. Ничего компилировать не нужно.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `photocraft` → справа **Releases** →
   «Последняя сборка» → файл `photocraft-studio-<версия>.zip`.
2. **Распакуйте** — внутри одна папка `photocraft`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/photocraft/`.
   Помощник сам найдёт ваш `auth.php` на два уровня выше (`/app/src/auth.php`)
   и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **nginx** — две обязательные настройки для этой папки (готовый пример: `nginx.conf.example`):
   - `client_max_body_size 20m;` — помощник отправляет снимок экрана;
   - `fastcgi_read_timeout 200s;` — модель может думать дольше минуты.

   После правки: `nginx -t && nginx -s reload` (или перезапуск контейнера nginx).
5. **Откройте** `https://ваш-домен/photocraft/` — войдите в систему, если ещё не вошли.
   Справа появится панель «Помощник».

Обновление — то же самое: скачать новый zip и заменить папку. Свой `studio/config.js`
перед заменой лучше сохранить.

## Что внутри папки

| Путь | Что это |
|---|---|
| `index.html` | Страница редактора |
| `app/` | Сам редактор (WebAssembly, сжат и разрезан на части) и загрузчик |
| `studio/` | Панель помощника: `studio.js`, `studio.css`, `ru-labels.json` |
| `studio/config.js` | **Настройки панели** — можно править прямо на сервере |
| `api/assistant.php` | Помощник: проверяет вход, отправляет запрос в Ollama |
| `api/settings.php`, `api/tools.php` | Внутренние настройки и список действий помощника |

## Настройки в `.env` (необязательно)

По умолчанию помощник берёт всё из вашей системы. Переопределить можно так:

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PHOTOCRAFT_MODEL` | Модель помощника (нужны картинки и tools) | `GLOBAL_MODEL` |
| `PHOTOCRAFT_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `PHOTOCRAFT_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `PHOTOCRAFT_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `PHOTOCRAFT_MAX_TOKENS` | Длина ответа | 2048 |
| `PHOTOCRAFT_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `PHOTOCRAFT_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

Запросы помечаются для шлюза как `photocraft` через ваш `enrichLLMPayload()`.

## Как работает помощник

- **Совет** — объясняет, где найти функцию и что выставить. Ничего не меняет.
- **Сделай** — сам выполняет команды редактора: находит нужную команду, открывает диалог,
  выставляет значения, нажимает OK, смотрит на результат.
  Каждое действие видно в ленте, у каждого есть кнопка «Отменить»; всё отменяется и Ctrl+Z.
  Удаление, слияние слоёв, закрытие и сохранение — только после вашего «Разрешить».
- **Подсказки к фото.** Открыли снимок — помощник смотрит на него и на точные цифры тонов
  (`document.toneStats`: яркость, провалы теней, пересветы, контраст, насыщенность, цветовой сдвиг)
  и предлагает 2–3 правки одной кнопкой, лучше корректирующими слоями. Вручную — «Подсказки к этому
  фото» в пустой панели. Выключить автоподсказки: `suggestOnOpen: false` в `studio/config.js`.
- **Запомнить как действие.** После работы помощника (или применённой подсказки) под ответом есть
  кнопка «Запомнить как действие»: шаги сохраняются экшеном (Окно › Экшены) с теми же параметрами,
  и его можно применить ко всем открытым документам. Можно и словами: «запомни это как „Фото для
  каталога“», «сделай так же со всеми открытыми».
- **Быстрая строка — Ctrl+Shift+Пробел** (или кнопка-молния в шапке панели): поле внизу над холстом,
  ответ всплывает над ним, вся история — в панели. (Ctrl+Пробел занят: это временная лупа, как в Photoshop.)
- **Домик** справа в верхней строке редактора — на уровень вверх (`homeUrl` в `studio/config.js`).
- **Глаз** рядом с полем ввода — показывать ли помощнику экран (снимок уходит только на ваш сервер).
- Кнопка солнца/луны переключает светлую и тёмную неоморфные темы — и панели, и редактора.
  Остальные темы доступны в редакторе: Окно › Тема.
- **Фирменная тема** — стекло на градиентном фоне: Окно › Тема › Тёмная тема › Фирменная
  (или Настройки › Интерфейс). Панель помощника переключается вместе с редактором; выбор
  запоминается. Вернуться к неоморфным — кнопкой солнца в панели.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Вместо редактора «Загрузка идёт дольше обычного» | Все ли файлы из `app/` скопировались; консоль браузера (F12) |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не найден auth.php системы» | Задайте `PHOTOCRAFT_AUTH_FILE` в `.env` |
| «Сервер помощника ответил не JSON» | PHP не обрабатывает `api/assistant.php` — проверьте блок PHP в nginx |
| Ошибка 413 | `client_max_body_size 20m` (пункт 4) |
| Ошибка 504 / ответ обрывается | `fastcgi_read_timeout 200s` (пункт 4) |
| «Модель не умеет вызывать инструменты» | `PHOTOCRAFT_MODEL` с поддержкой tools |
| «Модель не принимает картинки» | Выключите «глаз» или укажите мультимодальную модель |

Проверка помощника без панели: откройте `https://ваш-домен/photocraft/api/assistant.php` —
должно показать `{"ok":true,"model":"…"}`.

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Мост редактора: `apps/photocraft-web/src/control_bridge.rs` — `window.__photocraftNative.call(метод, json)`,
  те же методы, что в `docs/control-protocol.md`. В консоли браузера: `await photocraft.call('ui.inspect')`.
- Темы: `NeuLight` / `NeuDark` в `crates/ui-egui/src/theme.rs`, отрисовка — `widgets::surface`,
  `widgets::neu_raised_shape`, `widgets::neu_pressed`.
- Панель: `studio/web/`, сервер помощника: `studio/api/`.
